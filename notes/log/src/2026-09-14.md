## 学到的内容

1.grep : 查找文件中所要求部分,并将含所需部分的行打印。
语法：grep [options] pattern [files]
eg: grep -i[不区分大小写] '一'[查找的内容] novel1.txt[文件名/地址]
-注: 文件名是为了确定在哪个位置寻找，shell会根据内容后面的参数确定位置通常grep不能用在文件夹但是用flag: -r(递归寻找当前目录下及子目录)
2.find : 寻找文件或目录。
语法：find [路径] [匹配条件] [动作]
3.chmod : 更改用户对文件的权限
语法：  chmod [选项] 权限模式 文件...
        chmod [选项] --reference=参考文件 文件...
4.chown : 更改文件拥有者
语法: chown [选项] 所有者[:组] 文件...
      chown [选项] --reference=参考文件 文件...
5.ps : 显示当前进程的状态
语法: ps [options] [--help]
6.top : 提供了一个动态的、交互式的实时视图，显示系统的整体性能信息以及正在运行的进程的相关信息。
语法: top [-] [d delay] [q] [c] [S] [s] [i] [n] [b]
7.kill : 用于终止正在运行的进程。
语法: kill [options] <PID>  <PID> 是要终止进程的进程 ID。
8.df : 用于显示文件系统的磁盘空间使用情况
语法: df [选项]... [FILE]...
9.du : 用于显示目录或文件的大小。
语法: du [-abcDhHklmsSx][-L <符号连接>][-X <文件>][--block-size][--exclude=<目录或文件>][--max-depth=<目录层数>][--help][--version][目录或文件]
10.tar : 用于备份文件。可以与压缩工具（如 gzip 或 bzip2）结合使用，创建压缩的归档文件（如 .tar.gz 或 .tar.bz2）
语法: tar [options] -f archive.tar [files...]
