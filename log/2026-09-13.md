## 学到的概念

| 术语 | 一句话解释 |
|------|-----------|
| Repository（仓库） | 存放项目所有文件 + 全部修改历史的地方 |
| clone | 把云端仓库完整下载到本地，生成可工作的副本 |
| add | 把修改放进"暂存区"，相当于打包前装箱 |
| commit | 把暂存区的内容封存为一个带说明的存档点 |
| push | 把本地存档推送到 GitHub 云端，完成同步 |
| HTTPS 方式 | 用网址连接 GitHub，首次推送时浏览器登录授权一次即可 |
