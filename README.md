# robotics-lab

机器人方向的个人学习仓库：从命令行基础一路记到 ROS2 与 Webots 仿真。

---

## 这是什么

这是一个**学习日志仓库**，不是软件项目 —— 里面没有可编译的成品，只有每天的学习记录。

我目前是本科在读，目标方向是机器人控制与仿真。这个仓库用来：

- 记录每天学了什么、卡在哪、想通了什么；
- 把零散的知识点沉淀成可以回看的文档；
- 逼自己复盘 —— 很多东西写下来才发现其实没懂。

学习主线大致分三段：

| 阶段 | 主题 | 时间 |
|------|------|------|
| 打基础 | Linux / Shell、Git、vim、C++、线性代数 | 2026.09 起 |
| 工具链 | CMake、gdb、ROS2 工作空间与包管理 | 进行中 |
| 应用 | Webots 仿真、7 轴机械臂、e-puck | 后续 |

## 目录结构

```
robotics-lab/
├── README.md                  # 本文件：仓库说明
└── notes/
    └── log/
        └── src/               # 每日学习日志，一天一个文件
            ├── 2026-09-13.md
            ├── 2026-09-14.md
            └── ...
```

后续如果加入实际代码，会另开 `code/` 目录与 `notes/` 并列存放 —— 笔记归笔记，能跑的代码归代码。

## 日志的写法

每篇日志用同一套骨架，方便横向对比不同阶段的自己：

```markdown
# 学习日志 #编号 —— 标题

> 日期：YYYY-MM-DD
> 天气：
> 阶段：

## 今天做了什么

## 学到的概念 / 命令

### 完成比完美更重要
```

编号从 `#001` 连续递增，文件名与日志日期保持一致。

## 怎么使用

不需要构建，也不需要安装任何东西 —— 全部是纯文本 Markdown。想读的时候有三种方式：

**一、在线看（最省事）**

直接在 GitHub 仓库页面点进 `notes/log/src/`，打开任意文件，GitHub 会自动渲染成排版好的页面。

**二、克隆到本地看**

```bash
git clone git@github.com:1ucency/robotics-lab.git
cd robotics-lab
```

然后用 VS Code、Typora 之类的编辑器打开，左侧能看到完整目录树，右侧实时预览。

**三、命令行直接翻**

```bash
cat notes/log/src/2026-09-19.md     # 整篇打印
less notes/log/src/2026-09-19.md    # 分页阅读，q 退出
```

## 怎么更新

标准的提交三连：

```bash
git add -A                          # 把改动放进暂存区
git commit -m "log: 2026-09-20"     # 提交，说明写清楚
git push                            # 推到 GitHub
```

提交说明的惯例：日志用 `log: 日期`，文档改动用 `docs:` 开头，其他改动也尽量用一个动词短语概括做了什么、为什么。
